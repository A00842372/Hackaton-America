### Issue tracker

Las especificaciones y tareas se gestionan en GitHub Issues de A00842372/Hackaton-America. Para consultar, crear o actualizar issues, sigue `docs/agents/issue-tracker.md`.

Para clasificar issues o cambiar su estado, usa el vocabulario de `docs/agents/triage-labels.md`.

### Domain docs

El proyecto tiene un único contexto. Antes de explorar o modificar conceptos del dominio, consulta `docs/agents/domain.md`.
