# Etiquetas de triage

| Rol de la habilidad | Etiqueta en GitHub | Significado |
|---|---|---|
| needs-triage | needs-triage | Pendiente de evaluación |
| needs-info | needs-info | Falta información para continuar |
| ready-for-agent | ready-for-agent | Especificada para que un agente pueda trabajar |
| ready-for-human | ready-for-human | Requiere trabajo de una persona |
| wontfix | wontfix | No se implementará |

Usa estos nombres cuando las habilidades mencionen sus roles canónicos. Conserva las demás etiquetas del repositorio.
